# 🚗 Rider Hiker

**Rider Hiker** is a peer-to-peer ride-sharing app designed for intra-city hitchhiking. It connects everyday drivers and riders for casual, fuel-efficient, and community-driven travel within the city.

## ✨ Features

- 👥 Connect drivers and riders in real-time
- 📍 Share or request rides within city limits
- 💬 In-app ride confirmations 
- 🌱 Focus on fuel-sharing and eco-friendly commuting

## 🔧 Tech Stack

- **Frontend**: React Native (mobile app)
- **Backend**: Node.js with Express
- **Database**: MongoDB or similar (optional, configure based on use)
